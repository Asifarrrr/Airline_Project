# Airline Customer Satisfaction Predictor

An end-to-end machine learning project that predicts whether an airline passenger will be satisfied with their flight. A logistic regression model is served through a **FastAPI** backend and explored through an interactive **React** dashboard with a modern dark purple interface.

## Features

- **Satisfaction prediction:** enter a customer profile, flight details and 13 service ratings, and get a prediction with its probability.
- **Interactive analytics:** filter customers by flight distance and class, and watch the KPIs and charts update instantly.
- **Visualizations:** flight distance vs arrival delay, satisfied customers by class, and satisfaction by gender.
- **REST API:** a documented FastAPI backend with request validation (Swagger UI at `/docs`).
- **Single-file frontend:** React and Chart.js loaded from a CDN, so there is no Node.js build step.

## Getting started

### 1. Clone and install

```bash
git clone https://github.com/<your-username>/<your-repo>.git
cd <your-repo>

python -m venv venv
venv\Scripts\activate          # Windows
# source venv/bin/activate     # macOS / Linux

pip install -r requirements.txt
```

### 2. Train the model

```bash
python airline_model.py
```

This cleans the data, trains the model, and saves the model, scaler, column list and cleaned dataframe into `models/`.

### 3. Run the app

```bash
uvicorn app.airline_api:app --reload
```

Open **http://127.0.0.1:8000** for the dashboard, or **http://127.0.0.1:8000/docs** for the interactive API docs. The status pill in the top right of the dashboard shows "API connected" when everything is working.

## API reference

| Method | Endpoint | Description |
|---|---|---|
| `GET` | `/` | Serves the dashboard |
| `GET` | `/data` | Returns the cleaned dataset as JSON (used by the charts) |
| `POST` | `/predict` | Returns the predicted satisfaction and its probability |

**Example request**

```json
POST /predict
{
  "Gender": 1,
  "Customer_Type": 1,
  "Age": 35,
  "Type_of_Travel": 1,
  "Flight_Distance": 1000,
  "Inflight_wifi_service": 3,
  "Departure_Arrival_time_convenient": 3,
  "Gate_location": 3,
  "Food_and_drink": 3,
  "Online_boarding": 3,
  "Seat_comfort": 3,
  "Inflight_entertainment": 3,
  "On_board_service": 3,
  "Leg_room_service": 3,
  "Baggage_handling": 3,
  "Checkin_service": 3,
  "Inflight_service": 3,
  "Cleanliness": 3,
  "Departure_Delay_in_Minutes": 0,
  "Arrival_Delay_in_Minutes": 0,
  "Class_business": 1,
```

**Example response**

```json

```

`Prediction` is `1` for satisfied and `0` for neutral or dissatisfied.
